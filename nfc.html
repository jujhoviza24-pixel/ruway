📲 Grabar etiqueta NFC

Para que se abra acercando el celular, sin escanear.

Lo que va a abrir la etiqueta
—
Desde este celular se graba con una app gratuita
  1. Instala NFC Tools (App Store o Play Store).
  2. Copia el enlace con el botón de arriba.
  3. En la app: Escribir → Agregar un registro → URL / URI → pega el enlace → OK.
  4. Toca Escribir y acerca la etiqueta a la parte de arriba de tu iPhone (en Android, a la parte de atrás).
  5. Para que nadie la cambie: Otros → Bloquear la etiqueta. Es para siempre.

En Android con Chrome también se puede grabar desde acá mismo: abre esta página en Chrome.

Consejos
  1. Usa etiquetas NTAG213 (stickers redondos de 25 a 30 mm): las leen todos los celulares con NFC.
  2. Pégala detrás de la tarjeta, justo donde dice «acerca tu celular».
  3. Lejos del alambre de los limpiapipas y de cualquier metal: el metal apaga la señal.
  4. Pruébala siempre con tu celular antes de entregar. El QR sigue en la tarjeta para quien no tenga NFC.
